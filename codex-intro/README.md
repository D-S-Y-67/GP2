# Codex — An introduction

A self-contained, responsive introduction page. Open `index.html` directly or serve this directory with any static server. It has no runtime dependencies or network requests.

The published HTML includes its image, CSS, and JavaScript so it can travel as a single file. The separate `styles.css` and `script.js` files are included for easier code review. The page includes keyboard-operable example tabs, reduced-motion support, accessible section links, and a disclosure in the footer.

For Vercel: import the `codex-introduction-2026` branch of `D-S-Y-67/GP2`, set the Root Directory to `codex-intro`, and choose the static “Other” framework preset with no build command.
